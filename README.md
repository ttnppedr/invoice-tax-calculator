# 三聯式統一發票試算

紙本三聯式統一發票的填寫與稅額試算輔助。可從含稅總計或未稅銷售額互算 5% 營業稅、查財政部公開稅籍資料帶入買受人名稱，並產生新臺幣中文大寫。

本工具是試算草稿，**非正式統一發票**，不含字軌號碼，也不提供列印憑證。僅供參考，請自行核對。

## 本機執行

需要 Node.js 20+。

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的位址（預設 `http://localhost:43173`）。

或建置後以靜態檔開啟：

```bash
npm run build
npm run preview
```

`dist/` 可放到任何靜態空間。

## 怎麼用

- 含稅：先填「總計」，銷售額與營業稅依 `總計 × 5 ÷ 105` 四捨五入。
- 未稅：先填「銷售額合計」，營業稅＝銷售額 × 5% 四捨五入。
- 零稅率／免稅：營業稅＝0，總計＝銷售額。
- 統一編號旁的搜尋可輸入 8 位統一編號，通過檢查碼後查財政部資料，再帶入買受人名稱與統編。
- 買受人與發票日期不可手動編輯；日期與期別依裝置今天自動帶入。金額計算不依賴網路。
- 畫面是內頁式紙底加上框線表格，非正式發票，方便對照紙本抄寫。

## 稅額怎麼算

金額皆為新臺幣整數，**四捨五入至元**（看「角」位；`0.05 → 0`，`0.5 → 1`）。

| 情況 | 算法 |
| --- | --- |
| 應稅、先填總計（含稅） | 營業稅 = round(總計 × 5 ÷ 105)，銷售額 = 總計 − 營業稅 |
| 應稅、先填銷售額（未稅） | 營業稅 = round(銷售額 × 0.05)，總計 = 銷售額 + 營業稅 |
| 零稅率／免稅 | 營業稅 = 0，總計 = 銷售額 |

對照：含稅 105 → 銷售額 100、稅 5；未稅 100 → 稅 5、總計 105。

中文大寫用 壹貳參肆伍陸柒捌玖、拾佰仟萬億，例如 105 → 壹佰零伍元整。期別預設為今天的民國年與雙月窗。

## 統編資料來源

查詢使用財政部財政資訊中心「[全國營業（稅籍）登記資料集](https://data.gov.tw/dataset/9400)」公開 API，依 [政府資料開放授權條款第 1 版](https://data.gov.tw/license) 使用。免費、免 API Key；官方不保證 SLA，服務中斷時可稍後再查，金額計算仍可用。

本工具只送出使用者輸入的統編，不把金額或買受人名稱寫到自己的伺服器。
