# 發票稅額計算機

填手寫統一發票（GUI）時用來拆 5% 營業稅、對回銷售額／總計，並產生新臺幣中文大寫。純前端，資料不會送到伺服器。

僅供參考，請自行核對。

## 本機執行

需要 Node.js 20+。

```bash
npm install
npm run dev
```

瀏覽器開啟終端機顯示的位址（預設 `http://localhost:43173`）。

或建置後以靜態檔開啟：

```bash
npm run build
npm run preview
```

`dist/` 可放到任何靜態空間。

## 稅額怎麼算

採財政部常見寫法，金額皆為新臺幣整數，**四捨五入至元**（看「角」位，也就是十分位；`0.05 → 0`，`0.5 → 1`）。

| 情況 | 算法 |
| --- | --- |
| 應稅、先填總計（含稅） | 營業稅 = round(總計 × 5 ÷ 105)，銷售額 = 總計 − 營業稅 |
| 應稅、先填銷售額（未稅） | 營業稅 = round(銷售額 × 0.05)，總計 = 銷售額 + 營業稅 |
| 零稅率／免稅 | 營業稅 = 0，總計 = 銷售額 |

對照：

- 含稅 **105** → 銷售額 100、稅 5
- 未稅 **100** → 稅 5、總計 105
- 含稅 **1** → 稅 0、銷售額 1（`1 × 5 / 105 ≈ 0.0476`）
- 未稅 **1** → 稅 0、總計 1（`1 × 0.05 = 0.05`，角位為 0）
- 未稅 **10** → 稅 1、總計 11（`0.5` 進位）
- 含稅 **10** → 稅 0、銷售額 10（`10 × 5 / 105 ≈ 0.476`）

最後編輯的欄位是準：總計與銷售額會互相改寫。明細列一旦有數量、單價或金額，銷售額改由各列金額加總（金額 = 數量 × 單價）。

中文大寫用 壹貳參肆伍陸柒捌玖、拾佰仟萬億，結尾「元整」，例如 105 → 壹佰零伍元整。

發票期別預設為今天的民國年與雙月窗（1–2、3–4、…、11–12），可改。
